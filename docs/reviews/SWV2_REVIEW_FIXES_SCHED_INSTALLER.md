# SW-V2 independent review: fixes for scheduler, plan budget, installer purge, stray files (#17)

Base: `swv2-integrate` (merged twice, latest df9a86b). Each defect was checked against the code first, then fixed with a regression test, one commit each.

| # | Defect (verified) | Fix | Regression test |

| 3 | `latest_due` walked every missed occurrence (up to 50,000 `next_after` calls) synchronously inside `tick()`. A `*/5` job after 6 months off blocked the event loop for about 18 s, which stalled the voice and face link. | It now looks back from `now` in a doubling window (starting at 1 h) to find the latest occurrence.
