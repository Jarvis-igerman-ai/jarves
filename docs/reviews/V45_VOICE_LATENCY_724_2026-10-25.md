# V4.5 voice latency on installed JARVES 4.0.1.724 (issue #122), 25 Oct 2026

**Status: automatic silent measurement only. NOT human-verified.** No microphone, speaker or camera was used.
Build: installed JARVES 4.0.1.724 on this PC, run with its bundled Python. Owner's config (`combined`, `gpt-live-1`),
real GPT-Live over the internet, a throw-away data folder per run. The owner's data folder and running Core were not
used or changed (config and key were only read). Questions were synthesised locally and injected as audio; answers were
measured on a virtual speaker and never played.

## Results (seconds)

| Stage | 4.0.1.349 (25 Oct report, n=4 ok) | 4.0.1.724 now (n=5, median) | range |
|---|---|---|---|
| Core ready (cold, empty folder) | 6.4 | 3.0 | 2.8 to 6.1 |
| Core ready -> live session open | 12.2 (loading voice + connect) | 5.2 | 4.0 to 7.1 |
| Session open -> first greeting audio | 1.5 | 0.5 | 0.5 to 0.6 |
| Core ready -> first greeting audio | 14.0 | 5.7 | 4.6 to 7.6 |
| Failed greetings (no audio within 15 s, or crash) | 1 of 5 | **0 of 5** | |

Hebrew questions (one session, from end of question to first sound): "מה השעה?" 0.27 s; "מה מזג האוויר בתל אביב?" 0.75 s.
Note: the first sound for the weather question was a short lead-in ("אה רגע, בודק..."), so the real answer came later.
Time to the full answer was not measured in this run.

`jarves speedtest --class owner` x3 (not stored, throw-away home, so the history rows are n/a): status pass 3 of 3;
`openai_roundtrip_ms` 562, 250, 305; `features_list_ms` 2.5, 6.8, 34.1; `dashboard_first_load_ms` 31.5, 4.8, 10.0.

## Spend

About 110 s of live voice across 6 sessions plus 1 backend request. Estimated spend about 0.15 USD (cap 2 USD).

## Caveats

- Five starts is a small sample. 0 failures here does not prove the greeting stall (P0.4 Q05) is fixed; it was 1 of 5
  on 4.0.1.349. Keep the issue open until a larger run or a real-PC run shows it.
- The median before/now compares different runs on different builds, not a controlled A/B test.
- Stage markers wake->ASR, tool I/O and TTS-first-audio are still not exposed separately.
- Not measured: real microphone and speaker, echo gate, barge-in, Bluetooth headphones delay, wake word, perceived quality.
