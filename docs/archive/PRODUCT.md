# Product vision / future skills — dormant scope

Physical **stationary** AI companion/personal assistant for living room. Friendly animated round face, voice in Hebrew, music player, basic offline operation, camera (optional) and modular sensors (light, presence, temperature). Connected AI can be OpenAI cloud or optional home LAN inference server; internet only required for cloud/search/streaming, not face/locally stored media. Remote secure access via SSH/Tailscale and later user settings/dashboard.

Future skill suggestions ONLY, not tasks now: weather, timers, calendar, reminders, Gmail summaries with permissions, web Q&A, memory, Spotify or Music Assistant where compatible, optional Home Assistant.

Safety/privacy: physical mic switch ideal but requires actual hardware disconnect verified; camera indicator/shutter may be desired. Never store Google credentials in app code. Confirm sensitive actions before execution.

User priorities: visual beauty, physical realism, easy disassembly, extensibility, reliability, responsive voice, efficient agent development, no soldering if possible, minimize recurring voice/API costs. On-device heavy LLM is NOT required; optional LAN server meets future local-model aspiration.
