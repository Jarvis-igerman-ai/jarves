# Why no change was shipped

- The 2 s is the Windows delay before a refused connect to a closed localhost port (`cli._ws_call`, `open_timeout`); Linux CI
  refuses instantly, so a fix would not shorten CI. Avoiding it test-side means stubbing `_ask_core`, which removes the
  "Core is stopped" detection the test asserts. A product-side fix (skip the connect when the saved state says stopped) is a
  behavior change, out of scope here.
- The agents_system cost is the real Core + plugin subprocess round trip the test exists to cover; cutting it removes coverage.
