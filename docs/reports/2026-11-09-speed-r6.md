## Finding: no safe test-side cut
- The 204 s selfcheck test is the first test in its file. Re-run alone: 86 s; the next selfcheck test, which does the
  same `run()` on the same log, takes 1 s. cProfile shows the time is `_io.open_code`, `nt.stat` and file reads while lazily
  importing about 1766 modules (setup_wizard, guides, diagnose, skills, pydantic models). No sleep, no network. In an
  idle `python -X importtime` run the same imports cost about 11 s. The rest is disk/antivirus contention on this host.
- test_projectmgr tests spawn real git repos and subprocess agents; their `FAKE sleep` calls total under 1 s per test.
  The time is git/process startup under the same contention, so a fixture change cannot be measured reliably here.
- Sharing the import cost needs a module-level import in the test or a session fixture, which only moves the cost
  to another test. It is not a saving.

Result: no code change made. Before = after for all tests (no edit). Not claimed as a speed-up.
