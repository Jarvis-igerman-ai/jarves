# Phone page accessibility audit (JAR-141)

Scope: `core/src/jarves/dashboard_static/mobile/`. Static review only; no screen reader or real phone used (UNVERIFIED on device).

## Fixed (test: `core/tests/test_mobile_a11y_tabs.py`)
1. Tabs had no `aria-controls`, panels had no `role="tabpanel"` / `aria-labelledby`.
2. Drawer is `aria-modal` but Tab could leave it: focus is now trapped.
3. Tabs (vertical tablist) had no arrow / Home / End navigation.

## Not fixed (listed)
- Switching a tab does not move focus or announce the new page.
- App view has no `<h1>` (pair view has one).
- `#ptt` hold-to-talk is pointer-driven; keyboard alternative (Space/Enter toggle) unverified.
- Tab buttons are all in the tab order (no roving tabindex).
- Contrast of both themes was not measured; the CSS comment claims 4.5:1, unverified.
- Drawer outline may be clipped by `overflow` on the panel (needs a browser check).
