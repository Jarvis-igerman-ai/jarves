- Fixed: project manager approvals and owner texts (review command, merge approval, "merged" event, agent card, `ship` plan and approval) now name the exact commit, and `ship --apply` and owner merges land only the commit you approved; a changed task branch asks again, and work added during a merge is kept instead of deleted. Commands named in a project repository's own git config (merge drivers, config hooks, signing programs, filters, external diff/textconv, submodule recursion) no longer run in project manager git calls; a filter set only there stops the command, `ship` signs with your global or system signing settings (a per-repository signing key or format is not used; with no global key it signs with your global committer email), and uncommitted edits inside a submodule are not reported as changes. Needs git 2.38 or newer. Details and open limits: #1407, #1533.
