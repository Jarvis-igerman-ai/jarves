- Fixed: the built-in default autopilot worker allow list is now read-only (#1311). Removed: pytest, `<python> -m pytest`, npm, npx, ruff, mkdir and the git add/commit/merge/rebase/switch/worktree/fetch/branch rules. `git diff`/`git log` are allowed only as exact commands (no `--output=<path>` or its abbreviations). `gh pr|issue|run` are limited to read subcommands. Worker deny rules add `git diff|log ... --output`, `gh ... --web`/`-w`, `gh pr checks --watch` and edits under `.git`. Default workers therefore no longer run tests or commit; the owner can restore rules with `worker_allowed_tools` in autopilot.json.
