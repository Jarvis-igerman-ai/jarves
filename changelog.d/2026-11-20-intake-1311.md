- Fixed: the built-in default autopilot worker allow list is now read-only: pytest, `<python> -m pytest`, npm, npx, ruff and the git add/commit/merge/rebase/switch/worktree/fetch/branch rules are removed, and `git diff`/`git log --output` is denied, so a default worker cannot write autopilot.json through them (#1311). Default workers therefore no longer run tests or commit; the owner can restore rules with `worker_allowed_tools` in autopilot.json.
