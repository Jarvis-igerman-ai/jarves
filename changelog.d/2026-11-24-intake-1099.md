- Fixed: learned preferences, goals and dev drafts now refuse API keys and tokens (#1099): known token shapes; a named credential (api key, client secret, access token, private key, Hebrew equivalents) followed by ":"/"=" and any value; a bare "token" or "key" followed by ":"/"=" or, up to five words later, "is/was/הוא/היא/זה" and a 6+ character value with a digit or a non-hyphen symbol; and long high-entropy letter+digit segments, base64 "/" included. Merely naming or describing a token ("fix token refresh: done", "tokens: 5 left", "the token is expired", "key result: Q4-2026 revenue"), snake_case and camelCase identifiers, lowercase paths (at most two digits per part), UUIDs and pure-hex strings such as git SHAs stay allowed.
