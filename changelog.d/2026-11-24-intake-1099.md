- Fixed: learned preferences, goals and dev drafts now refuse API keys and tokens (#1099): known token shapes; a named credential (api key, client secret, access token, private key, Hebrew equivalents) directly followed by ":"/"=" and any value; a key or token word followed by ":"/"=" or, up to five words later, "is/was/הוא/היא/זה" and a 6+ character value with a digit or a non-hyphen symbol that is not a date, time or quarter; a 32+ hex or hyphen-grouped key at most two words after a key word; and long high-entropy letter+digit segments, base64 "/" included. Merely naming or describing a token ("fix api key loader: done", "tokens: 5 left", "the token is expired", "key dates: 2026-12-01"), snake_case and camelCase identifiers, lowercase paths (at most two digits per part), UUIDs and pure-hex strings such as git SHAs without a key word next to them stay allowed.
