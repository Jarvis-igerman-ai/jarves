- Fixed: learned preferences, goals and dev drafts now refuse API keys and tokens (#1099): known token shapes, a key/token word followed by a credential-like value ("token: ab12cd34", "my api key is ab.cd1234ef", or up to five words later "is/was/הוא/היא/זה" plus a 6+ character word with a digit or a non-hyphen symbol), and long high-entropy keys even when split by - _ or /, including bare 32-hex keys. Merely naming a token ("token refresh: fix it", "the token is SHA256", "set token: $GITHUB_TOKEN"), a token word before a URL, identifiers, camelCase names, paths, canonical UUIDs and 40/64-hex git SHAs stay allowed.
