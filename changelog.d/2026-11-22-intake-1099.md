- Fixed: learned preferences, goals and dev drafts now refuse API keys and tokens (#1099): known token shapes, a key/token word followed by a credential-like value ("token: ab12cd34", "my api key is ab.cd1234ef", or up to five words later "is/was/הוא/היא/זה" plus a 6+ character word with a digit or a non-hyphen symbol), and long high-entropy keys even when split by - _ or /, including bare 32-hex keys, repeated letter+digit groups ("abcd1234-efgh5678-...") and bare 40/64-hex or UUID-shaped strings. Merely naming a token ("token refresh: fix it", "the token is SHA256", "set token: $GITHUB_TOKEN"), a token word before a URL, identifiers, camelCase names, paths, and git SHAs or UUIDs in a URL path or after an id word or git verb ("commit", "sha256", "ticket", "id", "fix", "revert") stay allowed. Known limit: an all-letter value after a key word is allowed.
