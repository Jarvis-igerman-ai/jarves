- Fixed: the security-scan tracker (#480) now names the owner action next to each source whose access was refused: HTTP 401 says the scan token is missing, expired or invalid; HTTP 403/404 on Dependabot or secret scanning says to turn the alerts on if they are off and give the scan token read access. Transient errors and skipped sources get no action line. A body-template version in the tracker signature makes the next scan rewrite the tracker once, so the new line appears without waiting for a findings change; the signature drives only the tracker write and the scan result's `changed` flag, which sends no notification.
