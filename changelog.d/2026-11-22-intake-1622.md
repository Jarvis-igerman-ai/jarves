- Fixed: security hardening #1622: the project manager runs the GitHub CLI (`gh`) with `GIT_DIR` pinned to a path that can never be a git repository and with the temp area, not the project, as its working folder, so gh's own git reads no longer see the project's agent-writable git config (for example a planted `remote.origin.url`), even if that folder holds a repository. Issue list, pull request create and pull request checks take an explicit owner/repo, checked against a strict pattern and passed to gh as `--repo`; an empty or malformed owner/repo (a trailing newline or a folder path included) is refused before gh runs, and gh runs only the `auth`, `issue` and `pr` command groups.
