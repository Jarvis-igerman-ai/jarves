- Fixed: the dashboard unlock code can no longer be checked offline from the workflow files (#750). The running dashboard keeps an X25519 key in memory, publishes only its public key after binding and before listening, and removes it on a clean stop (only while it is still its own). `unlock.json` now holds an ephemeral public key and an HKDF-keyed HMAC tag instead of a 4-digit scrypt hash, so someone who can only read `access.token` and `unlock.json` can just guess online (5 tries). `jarvis workflow unlock` exits 2, and `open` shows no code, when no dashboard listens on the port, so a key left by a crashed server never yields a dead code. Known limit: an agent that can write files in the workflow home or run code as the owner can still create a code.
