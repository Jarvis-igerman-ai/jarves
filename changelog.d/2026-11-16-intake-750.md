- Fixed: the dashboard unlock code can no longer be checked offline from the workflow files (#750). The running dashboard keeps an X25519 key in memory and publishes only its public key; `unlock.json` now holds an ephemeral public key and an HMAC tag instead of a 4-digit scrypt hash, so a reader of `access.token` and `unlock.json` can only guess online (5 tries). `jarvis workflow unlock` exits 2 with a clear message when no dashboard key is published.
