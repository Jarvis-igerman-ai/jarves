- Fixed: project manager git commands no longer run commands named in the project repository's own git config (#1407): filter and merge drivers, config-defined hooks and signing programs from the repository config are switched off (a repository copy of a key you also set globally keeps your value) (a merge driver always gives a conflict, a filter keeps the file as it is), signing uses your own global or system program, diff/show/log run no external diff or textconv, and a config git cannot read stops the command. A git-lfs filter set only in the repository config no longer runs; set it in your global config. The owner's review command, merge approval, "merged" event, agent card and `ship` plan and approval now name the commit, and `ship --apply` merges exactly the commit you approved, even if the integration branch moves meanwhile.
