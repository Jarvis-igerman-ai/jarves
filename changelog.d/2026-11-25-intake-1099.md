- Fixed: learned preferences, goals and dev drafts now refuse API keys and tokens (#1099): known token shapes, a key/token word followed by a value ("token: ...", a 6+ character letters+digits word right after it such as "api key abc123", or up to five words later "is/was/הוא/היא/זה" plus a 6+ character word with a digit or a non-hyphen symbol or a 16+ letter passphrase, a bare "key" included), and long high-entropy letter+digit segments. Merely naming or describing a token ("fix token refresh expiry", "the token is expired", "the token is well-known", "rename token v2 handler"), snake_case and camelCase identifiers (also with a year, such as parseReport2024Quarterly), UUIDs and git SHAs stay allowed.
