- Fixed: privacy mode now also covers goal plans (#1526). With privacy on, new plan steps store no tool output: a step result is empty and a tool error keeps only its code. Plan text written before privacy was on is erased in one transaction at Core start and whenever privacy turns on (dashboard switch, the owner ending the full-text window, the window ending by itself, mask history). Step errors and plan notes keep their code (`step N: CODE`) or JARVES's own fixed reason (for example a timeout, a missing approval or a cost cap).
