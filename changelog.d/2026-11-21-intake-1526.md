- Fixed: when privacy mode is on at Core start, or is switched on later, the plan executor blanks plan text written before it in memory.db (step evidence and error, plan result and note) in one transaction and keeps only status and error codes such as `X_BROKE` (a code must contain "_"). Freed space is overwritten and the -wal file is checkpointed and truncated; a reader that keeps the checkpoint busy is logged as PLAN_PRIVACY_CHECKPOINT_BUSY. A failed scrub is rolled back, logged as PLAN_PRIVACY_SCRUB_FAILED and tried again after 30 s. Rows already scrubbed are not rewritten again (#1526).
