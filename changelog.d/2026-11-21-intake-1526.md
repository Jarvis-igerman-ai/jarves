- Fixed: privacy mode now also covers goal plans (#1526). With privacy on, new plan steps store no tool output: a step result is empty, and a step error or plan note keeps only its code (`step N: CODE`) or one of JARVES's own fixed reasons (for example a timeout, a missing approval, a cost cap or a restart), whichever code path writes it. Plan text written before privacy was on is erased in one transaction at Core start and whenever privacy turns on (dashboard switch, the owner ending the full-text window, the window ending by itself, mask history); the dashboard does this on its own memory.db connection. The goal plans guide says so.
