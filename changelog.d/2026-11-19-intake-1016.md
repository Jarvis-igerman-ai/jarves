- Fixed: `jarvis install-latest` no longer writes an extra `manual` backup before the verified pre-update backup (#1016); each install writes one archive there instead of two, and the report step "backup before install" names it (the rollback revert id). The install stops at that step, before anything changes, when no backup was made.
- Added: `jarvis backup settings --manual N --checkpoints N` sets the manual and checkpoint retention (only `--daily`/`--weekly` were settable before).
- Fixed: at least 3 of each checkpoint kind are always kept (`--checkpoints` below 3 is refused; prune treats an older stored lower value as 3), so the first start of the new version cannot prune the pre-update rollback archive.
