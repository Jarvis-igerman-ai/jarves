- Fixed: `jarvis install-latest` no longer writes an extra `manual` backup before the verified pre-update backup (#1016): each install now writes one archive there instead of two, and installs no longer fill the 10-slot manual retention; the report step is now "backup before install" and names that archive (the rollback revert id); `jarvis backup settings --manual N --checkpoints N` sets the manual and checkpoint retention (only `--daily`/`--weekly` were settable before); at least 2 of each checkpoint kind are always kept (`--checkpoints` below 2 is refused, prune treats an older stored lower value as 2), so the first start of the new version cannot prune the pre-update rollback archive; install-latest stops at the backup step, before anything changes, when prepare returns no backup.
