- Fixed: backups no longer fill the disk (#1016). Fewer backups are kept by default (3 daily, 2 weekly, 5 manual, 2 checkpoints). A backup checks free space first, removes old backups if needed and stops cleanly when the disk is still too full. The first start after an update reuses the update's fresh checkpoint when nothing changed since. New: `jarvis backup settings --manual/--checkpoints/--budget-mb`, and `jarvis doctor` warns when backups exceed the size budget.
