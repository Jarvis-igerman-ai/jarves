- Fixed: projectmgr: a project's check command (run by JARVES, or by an agent through its check rule) can no longer leave an entry in the repository's shared `.git/config` or rewrite the worktree's `.git` pointer. Both files are read when the run starts; if either changed, it is put back, the rejected text is kept in `<file>.jarves-rejected`, and the run fails. A run whose git config cannot be found is refused. Limits: `~/.gitconfig` and config include targets are not watched, and a change undone before the run ends is not seen (#1592).
