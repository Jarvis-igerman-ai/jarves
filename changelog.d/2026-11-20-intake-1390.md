- Fixed: project manager git calls no longer run commands named in a repository's shared git config (filters, merge and diff drivers, ssh, git proxy, editors, gpg, credential helpers); the owner's own global values still apply. A required filter with no owner command, or a repository `uploadpack`/`receivepack` setting, now stops the git call. Known residual: an agent that rewrites the config between JARVES's config read and the git call can still win (#1390).
