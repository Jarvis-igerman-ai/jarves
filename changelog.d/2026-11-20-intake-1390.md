- Fixed: the project manager's own git calls no longer run commands named in a repository's shared git config (#1390). Filters, merge drivers, ssh, editor, pager, askpass, gpg (including the ssh default-key command), trailer and config-hook programs set at repository scope (or in a file it includes) are replaced by your global/system value or git's safe default. When the repository adds a credential helper, the helper list is cleared and only your own helpers run. External diff and textconv are off for diff/show/log/blame, a push uses git's own receive-pack, `core.gitProxy` and the `ext::` transport are off. A repository config git cannot read now stops the call instead of reading as empty output. A repository-only filter (e.g. `git lfs install --local`) is off for JARVES runs; set it in your global config to keep it.
