- Fixed: project manager git calls no longer run commands named in a repository's shared git config (filters, merge and diff drivers, ssh, git proxy, `ext::` remote URLs, editors, gpg, credential helpers); the owner's own global values still apply. A required filter with no owner command, a repository `uploadpack`/`receivepack` setting, or a repository `includeIf` (it can match only inside a child git, such as the checkout of a new worktree), now stops the git call. Known residual: an agent that rewrites the config between JARVES's config read and the git call can still win (#1390).
