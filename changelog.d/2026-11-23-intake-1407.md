- Fixed: projects: `ship` names the integration commit in its plan, commands and approval prompt, and merges exactly that commit even if the branch moves after you approve. JARVES's git calls no longer run filter drivers, merge drivers, signing programs or config-defined hooks named in the repository's own git config: filters are skipped (a required filter stops the command), merge drivers become a conflict, `ship` signs with your global or system program, format and key, and hooks never run. Other config keys (such as diff drivers) are not covered (#1407).
