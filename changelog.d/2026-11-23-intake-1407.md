- Fixed: projects: `ship` names the integration commit in its plan, commands and approval prompt, and merges exactly that commit even if the branch moves after you approve. JARVES's git calls no longer run filter drivers, merge drivers, signing programs or config-defined hooks named in the repository's own git config: filters are skipped (a required filter stops the command), merge drivers become a conflict, `ship` signs with your global or system program, format and key, and hooks never run. Diffs run without external diff or textconv commands. A filter in the repository config marked required (for example Git LFS installed with `--local`) now stops with a message to set it in your global config. The ship merge message names the branch and the commit (#1407).
