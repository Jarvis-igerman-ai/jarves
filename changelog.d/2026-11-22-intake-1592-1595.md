- Fixed: projectmgr: an agent run or check command that changes the repository's shared `.git/config` is rejected and the config is restored; while such a run is active every JARVES git call restores it first, so a planted entry is not read, and a config that cannot be restored stops JARVES git instead (#1592). Any change during a run is reverted, the owner's own included: the replaced content is kept in `.git/config.jarves-rejected-*/config`, named in the rejection and logged as PROJECT_GIT_CONFIG_RESTORED. The GitHub branch push now goes to a pinned `https://github.com/<owner>/<repo>.git` from a private temporary repository that sees no repository-scope config, so `insteadOf`/`pushInsteadOf` and `http.*` keys in the shared config cannot redirect it or weaken TLS (#1595).
