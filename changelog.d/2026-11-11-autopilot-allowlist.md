- Fixed: the autopilot policy refuses a `worker_allowed_tools` override that could let a worker rewrite `autopilot.json`. Refused: a rule naming the file, a rule with non-plain characters, and any Bash rule whose command is not a bare read-only tool (`ls`, `grep`, `head`, `tail`, `wc`, `diff`, ...). git, gh, interpreters and pytest are refused in any form, because they take write options at run time (git `--output`, pytest `--junitxml`/`--basetemp`, `gh run download`) or run code a worker writes into the repository (conftest.py, hooks, repository config). The error names the rule and the reason. An existing override with a now-refused rule makes the policy invalid, so autopilot fails closed until the owner edits it. The built-in default worker list (no override) is not changed here. (#932)
