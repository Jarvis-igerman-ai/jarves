- Fixed: the autopilot policy now refuses a `worker_allowed_tools` override that could let a worker rewrite `autopilot.json`: a rule naming the file; a wildcard-only command (`Bash(*)`); a first word with a wildcard, `=`, quote, `$` or backtick; or a first word (also after removing a path, version, `.exe` or backslash escapes) that is an interpreter, shell, `.`/`source`, wrapper, file writer or general command runner (for example `Bash(python3.11:*)`, `Bash(sed -ni:*)`, `Bash(p\ython:*)`, `Bash(source:*)`, `Bash(make:*)`, `Bash(npx:*)`). Kept narrow forms: `Bash(<python> -m pytest:*)`, git with a fixed subcommand and no `-c`/`--upload-pack`/`--exec`, and `gh pr|issue|run`. An existing override with a now-refused rule makes the policy file invalid, so autopilot fails closed until the owner edits it. (#932)
