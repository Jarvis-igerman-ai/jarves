- Fixed: the autopilot policy now refuses a `worker_allowed_tools` override that could let a worker rewrite `autopilot.json`: a rule naming the file, a wildcard-only command (`Bash(*)`), an env-assignment or wildcard first word, or a command that starts with an interpreter, shell, wrapper or file writer in any version, path or `.exe` form (for example `Bash(python3.11:*)`, `Bash(sed -ni:*)`, `Bash(bash -lc:*)`, `Bash(env:*)`, `Bash(find:*)`). The narrow `Bash(<python> -m pytest:*)` form and ordinary rules such as `Bash(git diff:*)` still work. (#932)
