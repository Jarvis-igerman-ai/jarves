- Fixed: learned preferences, goals, goal plans and development drafts now refuse secret-shaped values that had no vendor prefix: hex keys of 32 or more characters (a bare 40-character value counts as a git SHA; a value of digest length 32/40/64/128 right after a hash word such as commit, sha256 or md5 counts as a checksum), a 40-character hex value near a key/token/secret word (also in names such as GITHUB_TOKEN or api_key), base32 seeds (TOTP), short random base62 tokens and base64 keys. Git commit SHAs (7 to 40 characters, even with six digits in a row, unless a key/token/secret word sits right before them), checksums named as such, absolute and relative file paths and CamelCase identifiers with short words and digits stay allowed (#1482).
