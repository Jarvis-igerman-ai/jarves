- Fixed: projectmgr pushes a branch only to the GitHub repository the owner pinned with `jarvis project config --github` (shown in its reply; `jarvis project github` warns when origin no longer matches the pin). An origin naming another repository is refused. Projects that already had GitHub turned on must run `jarvis project config --github write` (or `read`) once more to pin their repository. A regression test keeps the shared git config's insteadOf, proxy and sslVerify keys away from the push (#1595).
