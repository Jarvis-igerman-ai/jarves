- Fixed: the security-scan tracker (#480) now adds an "Owner action" line for each source GitHub refused with HTTP 401 (set a valid token), 403/404 on alert sources (turn the feature on or give the token read access) or 403/404 on workflow runs (give the token Actions read access), and a "Retry note" line (a snapshot from the last rewrite, no owner action) for other HTTP failures such as 429 or 503. A change in the refused 401/403/404 sources rewrites the tracker once; no refused sources keeps the old signature, and other HTTP failures do not change it.
