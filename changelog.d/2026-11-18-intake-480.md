- Fixed: the security-scan tracker (#480) now adds an "Owner action" line for each kind of source GitHub refused: HTTP 401 (set a valid token), 403/404 on Dependabot, code or secret scanning (turn the feature on or give the token read access), 403 on workflow runs (give the token Actions read access), 404 on workflow runs (check the workflow exists on main). A 403 that is a GitHub rate limit (`x-ratelimit-remaining: 0` or `retry-after`) is read as HTTP 429, retried, and is not a refusal. A change in the refused sources rewrites the tracker once; with no refused sources the signature is unchanged.
