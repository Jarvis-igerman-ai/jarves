- Fixed: a holder of only the workflow access token can no longer cancel the owner's unlock code with 3 + 2 wrong tries from two windows when the owner has a window that unlocked before (#1416). The 2 newest such owner windows are remembered across restarts (their stored session may last up to the 1-week unlock; other stored sessions stay capped at 12 h) and keep their own 3 tries, so a code allows at most 5 + 3 × 2 = 11 guesses of 10,000. Token-only windows share 5 tries and are then refused with `shared_exhausted` while the code stays live for an owner window. A window that has never unlocked, an ended owner window or a damaged stored owner list falls back to the old cancel at 5 shared tries.
