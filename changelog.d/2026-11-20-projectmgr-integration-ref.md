- Fixed: projects: an agent could move the shared integration branch (`git update-ref`) so its protected-file changes were never checked. JARVES now records the integration commit itself and diffs, merges, releases and ships that commit. It merges a task only at the commit it checked, even if another agent moves that task's branch. It re-checks protected files on exactly what it merges, and stops when a branch was moved outside JARVES. A project opened before this fix adopts its integration branch only when it has no protected changes (#1352).
