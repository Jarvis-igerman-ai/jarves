- Fixed: projects: an agent could move the shared integration branch (`git update-ref`) so its protected-file changes were never checked. JARVES now records the integration commit itself and diffs, merges, releases and ships that commit. It merges a task only at the commit it checked, even if another agent moves that task's branch, and re-checks protected and out-of-scope files on exactly that commit. It stops when a branch was moved outside JARVES. A project opened before this fix adopts its integration branch only when it has no protected changes (#1352).
