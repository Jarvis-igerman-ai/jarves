- Fixed: the dashboard unlock code can no longer be checked offline from files in the workflow home (#750). Each dashboard keeps an X25519 key in memory and publishes only the public half (also shown, without login, in `/health` as `unlock_pub`); `jarvis workflow unlock` stores an ephemeral public key and an HMAC tag, never a hash of the code. With no running dashboard, `unlock` exits 2 and gives no code. Known limit: an agent that can write the workflow home or runs programs as the owner's OS user can still make a code.
