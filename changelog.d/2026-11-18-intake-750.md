- Fixed: the dashboard unlock code can no longer be checked offline from the workflow files (#750). Each dashboard keeps a private key only in memory and publishes its public half; `unlock.json` now holds an ephemeral key and a keyed tag instead of a scrypt hash, so only the running dashboard can verify a code. `jarvis workflow unlock` exits 2 (and `open` prints a hint) when no dashboard listens on the port or its key is not published, so a stopped dashboard gets no code; a stopped dashboard removes its published key. Known limit: an agent that runs code as the owner's OS user can still mint a code.
