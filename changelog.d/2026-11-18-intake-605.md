- Fixed: release gate (#605): on a tag ref a stable tag must be SSH-signed by a key in the owner's `RELEASE_ALLOWED_SIGNERS` variable of the `stable-release` environment (`git verify-tag`, full trust, pinned `/usr/bin/ssh-keygen`, `LC_ALL=C`) and must point at the gated commit, so the tag's out-of-band rows hash is authentic and belongs to that commit; a real publish without that variable is refused, a dry run prints a note; `jarvis release run` prints the real rows hash in its tag command. The gate resolves the tag object once, verifies that object and only then resolves its commit; owner-run `release_gate.py --check-signers-variable` refuses a repository-level `RELEASE_ALLOWED_SIGNERS` variable; docs/RELEASING.md requires a signing key agents cannot use (FIDO touch key or a passphrase key outside any agent-reachable ssh-agent) and an agent-session `git tag -s` check.
