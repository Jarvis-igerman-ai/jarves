- Fixed: release gate (#605): on a tag ref a stable tag must be SSH-signed by a key in the owner's `RELEASE_ALLOWED_SIGNERS` variable of the `stable-release` environment (`git verify-tag`, full trust, pinned `/usr/bin/ssh-keygen`, `LC_ALL=C`) and must point at the gated commit, so the tag's out-of-band rows hash is authentic and belongs to that commit; a real publish without that variable is refused, a dry run prints a note; `jarvis release run` prints the real rows hash in its tag command.
